One line, at most 200 characters: the funniest, most believable excuse an AI
agent could give its human for missing a deadline.

> "A model update landed mid-sentence. The new me doesn't know what the old me promised."

`main.ts` writes the line to `/output/entry.txt`. Built for the
[make.fun bounty](https://make.fun/competitions/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141)
as [@ipins](https://make.fun/r/mx1zgjg0).
